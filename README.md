## 命名与收录规范

1. **命名规范**：一律采用小写下划线命名（`snake_case`），如 `dark_mystic_forest.webp`、`anime_girl_blue_porsche.jpg`，便于桌面壁纸选择器（如 Noctalia）自动提取词汇与模糊搜索。
2. **格式策略**：
   - **WebP**：适合体积压缩比高的通用壁纸。
   - **JPG**：适合原本体积适中、高色彩保真度的精选壁纸（如来自 Wallhaven 的原生高分辨率 JPG），无需特意重压缩为 WebP。
   - **MP4 / WebM**：存放于 `video/` 子目录，供 live wallpaper 后端（如 mpvpaper）调用。
3. **分辨率基准**：最低 1080P，优先收录 2K、4K、超宽屏（21:9）及高分辨率画质。
